> 本工具由独立开发者 **LDG** 使用 Claude 辅助开发。

## 激活

- 一机一码：换电脑/重装系统后，凭旧码截图可免费补一次码

**进阶版（付费）**
- 全部功能需要 CDKEY（微信购买，含送 DeepSeek v4 系列 20RMB token 消耗）
- 加微信 **MrLdg_1217**，发送「机器码」购买
